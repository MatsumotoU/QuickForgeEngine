# エディタのプロジェクト選択

`SelectProject.bat` を実行し、プロジェクトのルートフォルダーを選択します。エディタのビルド後にも選択画面が開き、画面を閉じるまでビルドの完了とデバッグ実行は待機します。変更がなくビルドが省略された場合は選択画面も開きません。ダイアログで新しいフォルダーを作ることもできます。選択結果は `project/EditorConfig.json` の `project_root` に保存されます。

エディタは作業ディレクトリ `project/` から起動します（Visual Studio のデバッグ実行も同じです）。設定中の相対パスはこの作業ディレクトリから解決されます。エディタは不足している `assets` 以下のフォルダーを作り、`project.json` がない場合は初期設定とデフォルトシーンを作ります。既存のファイルは上書きしません。プロジェクトを切り替えるときはエディタを終了してからスクリプトを再実行してください。
