# プロジェクトのアセット

各プロジェクトの `assets/` にモデル、画像、音声などの元ファイルを置きます。アセットブラウザへ外部ファイルをドロップすると、種類に応じたディレクトリへコピーします。OBJ は関連する MTL と画像も相対パスを維持してコピーします。同名のファイルは上書きせず、失敗を表示します。

アセットブラウザとヒエラルキーは `assets/` を走査し、配置したモデルや画像を相対パスでシーンに保存します。モデルの読み込み済みデータは ModelLoader が管理します。

エディターのデバッグ実行では、選択したプロジェクトとシーンをランタイムに渡します。ランタイムはプロジェクト内の `project.json` と `assets/` を直接参照します。シーンを指定しない場合は `project.json` の `start_scene` を使います。
