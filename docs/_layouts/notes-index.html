備忘録の追加方法

リポジトリの CreateNote.bat を起動し、タイトルや本文を入力すると、日付付きの Markdown ファイルが作成されます。作成したファイルをGitHubへpushすると、Jekyllが記事ページとこの一覧を生成します。

{% if site.posts.size > 0 %}

    • {% endfor %}
{% else %}

まだ備忘録はありません。テンプレートを使って最初のメモを追加できます。

{% endif %}
