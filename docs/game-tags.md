# ゲームのタグ

エディターの `Window > Game Config` でタグを追加・削除し、`Save Game Config` でプロジェクトの `project.json` に保存します。初期タグの `Default` は削除できません。追加したタグは保存前でも Inspector で選べますが、次回の起動後も使うには保存してください。

エンティティの `ObjectInfoComponent > Tags` では、一覧から複数のタグを選択できます。新しいエンティティと、タグが保存されていない以前のエンティティの初期値は `Default` です。タグをすべて解除することもできます。

`CollisionTriggerComponent > Accepted Tags` では、反応する相手のタグを複数選べます。指定が空ならすべてのタグに反応し、複数指定した場合は一つでも一致すれば対象です。`acceptedMask` の条件も設定されている場合は、タグとマスクの両方を満たす必要があります。相手に `ObjectInfoComponent` がない場合は `Default` として扱います。

ゲーム設定からタグを削除しても、既存のシーンやアセットのタグ指定は自動では書き換えません。Inspector に `(Missing)` と表示され、選択して解除できます。解除するまでは保存された名前で照合されるため、不要になった指定は各オブジェクトやトリガーから外してください。
