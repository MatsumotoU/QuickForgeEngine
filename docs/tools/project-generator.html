開発ツール / Windows

ProjectGeneratorの使い方

フォルダをプロジェクトのノードとして配置し、プロジェクト間の依存関係をつないで、Premakeの設定ファイルを生成するツールです。

このツールについて

ProjectGeneratorは、ソースフォルダの構成とプロジェクト同士の依存関係を画面上で整理し、ルートと各フォルダに premake5.lua を生成します。生成した設定をPremakeで処理すると、Visual Studioなどの開発用プロジェクトを作成できます。

このツールはVisual Studioのプロジェクトファイルを直接作るのではなく、Premake用の設定ファイルを生成します。

基本的な使い方

  1. ProjectGeneratorを起動します。
  2. メニューの File → Open Root Directory を選び、プロジェクト群のルートフォルダを指定します。メイン画面の Change Root Directory からも選べます。
  3. フォルダの読み込みが終わると、メイン画面にディレクトリツリーが表示されます。
  4. Add All Directories as Nodes を押してフォルダをまとめてノードにするか、必要なフォルダの Add Node を押して個別に追加します。
  5. ノードを並べ、必要なプロジェクト間の依存関係をつなぎます。
  6. 必要に応じて各ノードやワークスペースの設定を調整します。
  7. File → Generate Premake Hierarchy を選び、Premakeファイルを生成します。

ノードと依存関係

ノードを追加する

ノードはプロジェクトとして扱うフォルダを表します。まずは必要なフォルダだけ追加し、画面が込み入る場合は Arrange Left to Right で配置を整理できます。

依存関係をつなぐ

依存関係図では、左側に下位のプロジェクト（他のプロジェクトから利用される側）、右側に上位のプロジェクト（下位を利用する側）を配置します。ノード左側ほど下位、右側ほど上位です。

接続は、左側の下位ノードの右端にある out から、右側の上位ノードの左端にある in へドラッグします。たとえばゲームがエンジンを使う場合は「エンジン（左・下位）→ ゲーム（右・上位）」です。

接続の設定では、下位の依存関係も含めるか、接続先のプロジェクトだけを含めるかを選べます。画面上では赤が下位依存も含む設定、緑が接続先だけを含む設定です。

グループを使う

関連するノードをまとめて選択し、グループにすると、生成されるPremake上のグループ名を設定できます。

設定の調整

ノードを選択して Open Selected Node Settings を押すと、プロジェクト名、プロジェクト種別、インクルードパス、定義、リンク先などを設定できます。設定は構成（Debug、Development、Releaseなど）ごとに調整できます。

Edit → Common Premake Settings... では、ワークスペース名、アーキテクチャ、C++規格、構成名、共通の定義やビルドオプションを設定できます。

既存のPremake設定を取り込む場合は File → Load Root Premake、Visual Studioソリューションを取り込む場合は File → Load Visual Studio Solution... を使います。

Premakeファイルを生成する

File → Generate Premake Hierarchy を実行すると、選択したルートフォルダと各プロジェクトフォルダに premake5.lua が生成されます。生成後はステータス欄で結果を確認してください。

生成されたファイルをPremakeで実行し、Visual Studioなどで使うプロジェクトファイルを作成します。Premakeの実行方法や生成アクションは、利用する環境の設定に合わせてください。

設定の保存と読み込み

ノードの配置や依存関係、各種設定を再利用するには、File → Save Configuration As... でJSON形式の設定を保存します。次回は File → Load Configuration... から読み込めます。

設定ファイルにはルートフォルダへのパスも保存されます。別の場所に移動した場合は、読み込み後にルートフォルダを確認してください。
